Privacy Policy

Last updated: November 13, 2026

This policy covers Video Studio Uploader, a private tool used by the owner of Kayan Studio to manage the owner's own YouTube channels.

What the tool accesses

When the owner connects a YouTube channel, the tool receives Google OAuth tokens and uses the YouTube API Services to upload videos, set thumbnails and captions, read the channel's own video list, and read the channel's own analytics.

How data is stored

OAuth tokens and video files stay on the owner's computer. The tool has no server, sells no data, shows no ads, and shares nothing with third parties. It sends data only to Google, through the YouTube API Services, to perform the actions above.

Removing access

Access can be revoked at any time from the Google account security settings at myaccount.google.com/permissions. Revoking access stops the tool from reaching the channel; the owner then deletes the stored tokens.

Google and YouTube

This tool uses YouTube API Services. By using it you are also bound by the YouTube Terms of Service, and Google's handling of data is described in the Google Privacy Policy.
